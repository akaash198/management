Platform Architecture

Six Pillars of the
Cowrk Engine

Built on a modern, cloud-native stack designed for 10M+ active users and real-time collaboration across 150+ countries.

1

Real-Time WebSocket Layer

Django Channels 4 + Redis Channel Layer power live task updates, presence indicators, and instant messaging without manual refresh. Every board stays in sync with a live 30-second heartbeat.

2

AI Orchestration & Smart Assistance

Pluggable LLM layer supports OpenAI, Anthropic, Google Gemini, and private fine-tuned models. Powers daily briefings, sprint planning, task generation, and automated client reports grounded in your actual project data.

3

Granular Permission Engine

Five-tier company hierarchy (CEO → Admin → Manager → Member → Viewer) with four project-level roles and field-level access controls via django-guardian — enterprise governance without enterprise complexity.

4

Async Task & Automation Engine

Celery 5.3 handles background jobs — recurring task generation, notification dispatch, report compilation, and no-code rule execution — without ever blocking the UI thread.

5

WebRTC Peer Collaboration

SimplePeer-powered HD video with screen sharing and co-annotation. Every meeting is recorded, transcribed by AI, and attached directly to the project that spawned it — zero manual linking.

6

Cloud-Native & Mobile-Ready

Next.js 16 + React Native share business logic across web, iOS, and Android. Containerised microservices deploy on AWS, GCP, Azure, or fully on-premises via Docker Compose.
